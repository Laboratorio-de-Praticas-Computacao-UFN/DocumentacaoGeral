# Documentação Geral - Laboratório de Práticas da Computação - UFN
Repositório de apoio com os tópicos fundamentais, roteiros de estudo e ferramentas essenciais para as atividades práticas do laboratório.

### Tópicos já estudados

  - Docker: Conceitos de conteinerização, criação de imagens e gerenciamento de ambientes isolados para execução de projetos.

  - GitHub: Fluxo de trabalho com controle de versão, gerenciamento de branches, abertura de pull requests e colaboração em equipe.

### Conceitos importantes a serem estudados:
  - Boas práticas de programação
  - Estruturação de projeto
  - Organização de documentações
  - Padrões de desenvolvimento utilizados no laboratório.
  - Pacote, Biblioteca, Framework e API
  - Framework Bootstrap: html e css
  - Javascript ou Typescrit
  - Framework Django
  - Modelo arquitetural MVT (Model View Template)
  - Mapeamento Objeto-Relacional (ORM): makemigrations e migrate
  - API: IA Generativa
  - Estudar e usar o Open Router
  - Bibliotecas: Pandas, Numpy e Matplotlib
